### Quick Note
The default animations need to be changed no matter what. 
If you do not change them, you will get an error and the animations won't play.

### Finding your Animation's ID
To find your Animation ID, navigate to your Creator Dashboard and find the animations. 
Click on the one you want to swap and copy the string of numbers in the link. This is your Animation ID.
If you don't own the game place, you may need to allow the game or owner to use the animations.

### Changing the Default Animations
Navigate to ReplicatedStorage/Classes. Open the Character script.

#### Changing the Default **Killer** Animations
Find the function called `CharTypes:GetDefaultKillerSettings()`.
Scroll down to the AnimationIDs list.
It should look something  like  this.
```lua
    AnimationIDs = {
        IdleAnimation = "rbxassetid://(id)",
        WalkAnimation = "rbxassetid://(id)",
        RunAnimation = "rbxassetid://(id)",
        SlashAnimation = "rbxassetid://(id)",
     },
```

Swap out the default animation IDs with your animation IDs.

To find these, navigate to your Creator Dashboard and find the animations. Click on the one you want to swap and copy the string of numbers in the link. This is your Animation ID.

#### Changing the Default **Survivor** Animations
